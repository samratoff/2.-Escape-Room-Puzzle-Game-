Escape Room Puzzle Game 
 
Escape Room Puzzle Game is a Java Swing-based puzzle adventure game where players solve different puzzles and clues to escape from a virtual room. The game enhances logical thinking and problem-solving skills through interactive challenges. 
 
Key Components 
•	Java Swing GUI 
•	Puzzle Management System 
•	Clue Generation Module 
•	Timer System 
•	Score Tracking System 
•	Game Progress Management 
 
Working Process 
      The player starts the game in a locked room. 
      Different puzzles and clues are displayed. 
      The player solves puzzles to unlock new clues. 
      Progress is tracked throughout the game. 
      The game ends when the player successfully escapes. 
 
Expected Outcome 
•	Interactive puzzle-solving experience. 
•	Improved logical thinking skills. 
•	Better understanding of Java GUI and event handling. 
•	Practical implementation of game development concepts.
